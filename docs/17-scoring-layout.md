# 看图与评分同屏

逐题评测时，中间的长题干会把生成图推到页面下方；原来的评分面板也随整页滚走，评测员必须反复寻找图片和评分项。

## 交互调整

- 桌面窗口中，题目列表、题目与图片、评分表单分别滚动。图片不随评分表单滚走；评分状态和操作按钮始终保留在面板内。
- 已有生成图的题目默认收起“题目与参考图”，优先展示图片。无图的新题默认展开要求；上传生成图后收起题干。可随时用鼠标或键盘展开、查看参考图并放大。
- 收起详情后，在图片区上方固定显示题号和实际需求描述，默认最多两行；短窗口显示一行。“验收要点”可单独展开查看，“展开详情”打开完整需求与参考图，并回到题目起点。
- 摘要位于图片滚动容器之外，有正常占位，不覆盖图片、缩略图或上传按钮。长验收列表在摘要内单独滚动；滚动图片时，摘要位置保持不变。
- 切换题目或产品后，中间和右侧滚动位置回到起点。展开题干、浏览图片不修改分数或评测记录。
- 中等宽度将题目导航改为顶部横向列表，保留搜索；极矮窗口精简静态说明，将操作按钮排为一行，保存草稿使用带名称和提示的图标按钮。
- 手机宽度保留单列页面滚动，避免挤压图片与评分选项。
- 评测页默认使用紧凑工具栏，去掉重复规则条、大标题说明和常驻操作说明；“评测操作说明”可按需展开。缺少必需参考图等阻断提示仍显示。
- 点击“专注评测”收起项目侧栏、顶部面包屑和题目列表，扩大图片与评分区域。顶部保留题目选择、前后切题、展开题目列表及“退出专注”；无图片弹窗时也可用 `Esc` 退出。题目列表按需在布局内展开，不覆盖图片。
- 专注切换只改变布局，不重新挂载评测组件、不更改评分及项目数据。未保存输入保留；切题继续沿用未保存确认。图片按可用高度放大，评分操作按钮保留在面板底部。

## 实现边界

布局仅在已成功打开的正式项目“逐题评测”路由生效，不影响项目配置、同步、归档或报告页面。容器按窗口高度分配剩余空间，移除该路由原有的 650px 最小高度及 900px 固定高度。保存、评分计算、图片原始字节及项目版本规则沿用现有逻辑。

## 验证

浏览器使用独立的合成项目验证长题干、八条验收点、两张参考图、两张生成图、图片放大、评分栏滚动、提交后自动换题、草稿保存与上传后的展开状态。长题干滚到参考图时，评分栏和底部操作按钮仍在窗口内；提交后两栏回到起点。

检查桌面三栏、1024px 双栏、768×450 矮窗口及 390px 手机宽度：桌面页面没有额外的整页滚动或横向溢出，评分表单保留可滚动高度，按钮未被截断；手机恢复单列。自动测试与生产构建继续通过。

固定题目摘要补充验证：图片区域滚动前后摘要坐标不变；展开验收点、打开全文、收起全文和切题后展示内容及滚动位置正确；1024×600、1024×450 使用紧凑摘要与适应高度的图片，390px 宽度保持自然页面滚动。

专注评测补充验证：1280×720 窗口中，常规工作区由约 541px 增至 604px，专注工作区高 650px，主图高 455px；无横向溢出，底部保存与提交按钮保持可见。合成项目验证了未保存评分依据在进入、退出专注后保留、题目列表展开与收起、顶部切题、操作说明展开，以及图片弹窗的第一次 `Esc` 只关闭图片、第二次 `Esc` 退出专注。切换项目或离开评测页会重置专注状态；短屏样式保留操作说明入口及内容。
