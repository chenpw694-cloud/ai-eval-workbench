# Word、Excel 与一个 ZIP 的交接

用户需要阅读、交作业和继续协作时，不必手动阅读 JSON。格式按用途提供，既有格式仍可使用。

| 用途 | 入口 | 文件 | 能否导回 |
| --- | --- | --- | --- |
| 提交作业、继续编辑结论 | 报告与检查 → Word 报告 | `.docx`，含结论、1–5 分得分、GSB、已选择案例及最佳图 | 报告不是项目备份，不用于导回评分 |
| 查看评分与核对数据 | 报告与检查 → Excel 明细 | `.xlsx`，七个工作表 | “题库”工作表可作为题库导入；修改评分表不回写记录 |
| 整理题目 | 项目与题库 → 题库管理 → 下载模板 / 导出题库 | Excel、Word 表格；另保留 CSV 模板和 JSON 题库 | 选择文件、匹配列、预览后确认保存 |
| 三人传递初评及汇总 | 阶段同步 → 生成数据包 → 下载团队交接 ZIP | 一个 ZIP，附 Excel 阅读副本、说明、原清单和原图分包 | 整个 ZIP 直接导入阶段同步，无需解压 |
| 独立评审任务与返回 | 质量控制 / 自家对比 GSB / 独立评审空间 | 评审交接 ZIP | 任务在独立评审空间接收；判断在原项目收回 |
| 保存固定版本 | 版本归档 → 下载完整归档 ZIP | 冻结的原文件组 | 在版本归档中复核；不会重算并改写旧归档 |

## 最常用的三步

1. 想看分数：在“报告与检查”下载 **Excel 明细**，打开“结果汇总”或“逐题评分”。
2. 想交报告：先在“撰写结论”保存结论和典型案例，再下载 **Word 报告**。缺项会标为待补齐，不自动生成产品结论。
3. 想发给队友继续做 GSB：在“阶段同步”选择合适用途、发送成员并生成，下载 **团队交接 ZIP**，发送这一个文件。接收者直接选择这个 ZIP，检查预览后确认。是否能进行 GSB 仍取决于该组自家和竞品的有效初评与最佳图。

## 题库导入

支持 `.xlsx`、`.docx`、`.csv`、`.json`，单文件最大 20 MiB。Office 文件在浏览器本地读取。旧 `.xls`、`.doc` 请先用办公软件另存为新格式。

- Excel：推荐使用“题库”工作表，第一行为列名，每行一道题。支持多个工作表选择、文字、数字、布尔值、富文本。存在名为“题库”或“评测题库”的表时优先读取它们，便于从导出报告中复用题目。公式需先复制并粘贴为值，避免带入过期结果；不执行导入文件里的公式。
- Word：支持模板式题目表格，每行一道题。可选择多个表格；自由段落、扫描图片和任意排版的规则文档暂不自动拆成题目。表内嵌入的图片不会随题库导入，请通过“批量导图”关联实际文件。
- 标准字段：题号、题目标题、场景、品类、难度、需求描述、验收要点、参考图文件名。题号、需求描述、验收要点沿用已有必填规则。支持自定义列名的映射，未映射的列保留为自定义字段。
- Word 题库导出保留八个标准字段；需要完整自定义字段时使用 Excel / JSON。参考文件名不等于图片文件。
- 先预览，不直接写入。重复题号、缺失必填内容或格式错误会明确提示。整体替换需明确选择并确认。评测已开始的题库仍锁定，需通过“重新开始”创建可编辑新草稿。

Office 容器检查限制文件数量与展开大小，拒绝损坏、路径不安全及不受支持的 XML 声明。题目表格最多约 5000 行、100 列；并不表示已完成该规模的压力验证。

## 文件内容和边界

Excel 明细包含“结果汇总、维度得分、逐题评分、GSB对比、高频问题、交付检查、题库”。分数和百分比保留数字类型。草稿、无效提交、过期 GSB 和缺项会标记；不补成满分。当前导出是快照，不提供通过编辑 Excel 覆盖评分历史的能力。

Word 是可编辑的报告草稿，保存人工结论、已有统计、GSB、典型案例与当前缺口。总分使用 1–5 分；旧网页报告中的百分制与之为线性换算。没有完成评测也可导出草稿，不代表最终归档通过。仅嵌入所选典型案例的最佳图；每张图上限 12 MiB，嵌图累计上限 60 MiB。原图缺失、校验异常、超限或浏览器无法解码时，写入清楚的图片缺口和文件名，其他报告内容继续导出。完整原图须保留交接包。

单个交接 ZIP 上限为 256 MiB。大项目使用展开项里的原清单和 ZIP 分包；原有阶段协议及校验继续适用。封装保持内部文件字节不变，SHA-256 校验后再走原有导入与冲突流程。Excel 只根据本次导出清单里的数据生成，不扩大初评提交包或独立任务包的可见范围。修改阅读副本会导致包的完整性检查失败，请在工作台更正后重新导出。

固定归档 ZIP 直接封装原文件组，不额外生成新 Excel 来替代历史报告。原先 JSON 完整备份、旧清单加分包、Markdown 和 JSON 报告入口保留。

## 验证

新增格式测试覆盖中文多行题库、XML 字符、空模板、自定义列、公式隔离、数值类型、未完成状态、Office 容器错误、交接包字节往返及篡改拒绝。浏览器用合成项目验收 Excel / Word 下载、题库往返、一个 ZIP 的下载和重新上传预览。Word 经实际分页渲染检查中文、表格与案例图，Excel 经读取和渲染核对数值与空白。

文件能力在 `src/core/officeQuestions.ts`、`readableWorkbook.ts`、`wordReport.ts`、`handoff.ts`，按需加载 Office 库；评分逻辑仍使用既有评分引擎。
