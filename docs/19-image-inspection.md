# 原图细节查看

逐题评测中，点击生成图、参考图或历史参考图，进入同一个原图查看器。

- 鼠标移到图片区域，向上滚动放大、向下滚动缩小。缩放围绕指针所在位置，滚轮不会带动背后的评测页面。
- 图片放大超过查看区域后，可按住拖动。边界限制避免将整张图片拖出窗口。
- 工具栏提供缩小、放大、实际缩放比例、原始大小（1:1）与重置。100% 表示一个图片像素对应一个 CSS 像素；重置表示适应窗口，小图不会自动放大。
- 双击放大或还原。聚焦图片区域后，`+` / `-` 缩放、方向键移动、`0` 重置、`1` 原始大小；`Escape` 关闭弹窗。
- 每次重新打开、切换图片均恢复适应窗口。调整窗口尺寸时，适应模式重新计算大小；手动缩放保留倍率并重新限制拖动边界。

当前倍率范围为最小 `min(适应窗口倍率, 25%)` 至最高 `800%`。放大用于观察原始图片已有细节，不增加分辨率或修改原图；缩放、拖动不写入评测分数、素材或项目版本。

实现采用独立 `ImageInspector` 组件；几何纯函数位于 `core/imageViewport.ts`。单测覆盖适应窗口、指针锚点、倍率及各轴拖动边界、无效输入、像素/行/页滚轮单位。浏览器使用合成评测图片验证滚轮、拖动、重置、重新打开及小窗口布局。
