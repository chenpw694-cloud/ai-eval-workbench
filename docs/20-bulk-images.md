# 文件夹批量导图

## 使用流程

从正式项目侧栏“批量导图”、逐题评测顶部工具栏或“生成结果”旁的同名按钮进入。评测开始后仍可追加导图，顶部按钮在专注模式中也保留；不需要重新创建项目。跳转前先保存当前草稿，未保存修改仍沿用离页确认保护。

1. 用途选“素材图 / 参考图”，默认“按题目中的商品名称自动匹配”，选择素材文件夹。
2. 题目指定的参考图文件名、题干中的文件名或 R 编号会优先匹配；商品名称来自图片名称或商品对应表。例如 `1.png → 精华液`，自动关联所有包含该商品名的题目，不必复制四行。数字文件名本身不包含商品信息时，会提示填写一次商品名称，或导入已识别好的商品对应表。修改名称后点“根据商品名自动匹配”。
3. 每题只有一个必需参考图位置时自动绑定该位置；有多个位置时选择其一。原始文件名显示在列表，原图字节保持完整。
4. 查看“1 张图片 → 4 道题”等统计及每行匹配依据，点击“自动检查”。系统检查原图与对应关系后自动滚到预览；底部显示待处理原因或“检查完成，可以导入”，核对后点“确认导入”。图片数量不必等于题量。
5. 用途切换为“产品生成的评测图”，默认按数字文件名，选定产品，再选择其生成图文件夹。`1.png` 对应当前题库第 1 题，`02.jpeg` 对应第 2 题；数字指题库实际顺序，不取题号里的数字。超出题量可手动关联或跳过。导入后进入逐题评测继续检查、选最佳图和评分。

商品对应表是本机 JSON，可导入、导出复用，格式如下。别名用顿号分隔，路径可用于区分不同文件夹中的同名图。对应表只提供匹配依据，不重命名原图、不修改题库。

```json
{"1.png":"精华液、精华液瓶","2.png":"白T恤、白色T恤"}
```

自动匹配使用文字与已提供的商品名称，不调用图片识别模型，不会从纯数字文件名猜商品。同一题同时命中多张候选图时留待确认；题目有多个参考位置且无法确定时要求选择位置。每行显示匹配依据，可手动修正，不合适的可取消勾选。

也支持多选图片、按目录题号/参考图文件名自动识别、逐行改用途/题目/产品，以及复制同一图片的关联行用于其他题目。上方默认设置只影响接下来加入的文件；列表里的生成图产品可通过专门按钮批量调整。

PNG、JPEG、WebP、GIF 每张最多 25 MiB；非支持文件会忽略并计数。文件夹可包含子目录。列表每页 40 行，缩略图按需读取；读取并检查全部勾选图片后才开放确认按钮。

## 保存语义

- 参考图按题目共用，只追加当前参考图绑定修订，不制造空评测记录。相同位置与内容跳过；同名不同内容默认阻止确认，只有显式勾选替换才更正。旧图和历史评分保留。
- 生成图追加到对应题目与产品的草稿。已有评分、备注、耗时和旧图片检查保留，新图可用性与侵权状态为未确认；不会自动评分。若原任务已提交，增加图片会产生新草稿，需要重新提交。
- 单张且没有最佳图的任务会选为最佳图，多图保留已有最佳选择；可用性仍需人工判断。
- 当前记录中同名同内容的生成图跳过。历史中移除过的同名同内容图片可复用原资产 ID 重新加入，保留旧修订，不改写原图。
- 原有独立复评、GSB、联合评审使用固定基线，不因导图重写。已有固定任务时确认页提示可能需要重新安排。
- 草稿导图不会自行冻结项目，仍按开始评测、分发或正式提交的既有规则冻结。

## 原子保存与同步

导入前检查图片类型、大小、解码、SHA-256 和归属。确认时对项目、全部评测修订、素材元数据及参考图历史重新读取并核验快照，在一个 IndexedDB 事务内重新生成计划、添加图片和追加修订。其他页面已修改或存储空间不足时整体回滚；失败后刷新项目数据，再次校验即可重试。

不增加新数据库表或文件协议。批量导图产生的参考图修订和固定引用继续使用 schema 3，能随完整备份、阶段包和归档传递。图片仅存当前浏览器，跨设备仍通过阶段同步或项目备份交接。

## 验证

纯函数测试覆盖数字顺序、题号边界、越界与冲突、重复图片、参考图替换/恢复、生成图草稿保留原评分、同批参考快照、版本指纹及 schema 3 备份/ZIP 往返。浏览器使用合成素材文件夹和生成图文件夹验证目录选择、跳过多余编号、批量入库、重新打开逐题页、重复导入和另一页面更新后的拒绝覆盖。

评测中入口补充验证：已冻结且含既有评分的合成项目中，普通模式与专注模式均显示顶部及生成结果旁入口；分别点击两个入口可进入本项目的批量导图页，返回逐题评测后既有图片和评分仍显示。生产构建通过。

按题目自动匹配补充验证：合成项目使用 5 题、2 张数字命名图片，导入 `1.png → 精华液` 的商品表后自动生成 4 条共用关联，未提供商品信息的图片显示待处理；跳过后显示“1 张图片 → 4 道题”，自动检查后可确认。导入后四道相关题显示同一原图，第五道无关题没有误配。导出备份核对原始字节摘要与大小一致，只新增 4 处参考图绑定，不制造评测评分记录。纯函数测试覆盖共享图、数字名不猜题、商品别名与中英文边界、冲突候选、参考位置和路径区分。
