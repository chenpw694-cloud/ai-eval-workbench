# 界面预览功能与限制

## 当前目标

本轮根据“先弄出界面，看功能元素”的要求实现可交互预览，用来确认导航、布局、信息层级和主要操作。预览不代表本次真实评测已经执行，也不代表所有生产功能已经完成。

## 可体验的页面

| 页面 | 功能元素与实际行为 |
| --- | --- |
| 项目总览 | 任务完成度、可用率、复评、存疑卡片；阶段进程、产品表、待办与样本入口；统计为固定示例 |
| 方案与题库 | 七个维度权重编辑、合计 100% 校验、本地保存；25 标签搜索与筛选；项目信息编辑 |
| 我的任务 | 50 条占位题列表、关键词/场景/状态筛选、分页、勾选导出；编辑走查与功能检查勾选保存 |
| 逐题评测 | 题目导航、需求与验收点、商品图与最佳图选择、原图读取、问题标签、维度分预览、耗时/张数/失败/备注、草稿与提交 |
| 质量控制 | 校准与复评说明、固定示例一致率、三条示例分歧、查看差异、记录裁决并保留原始示例 |
| 对比评审 | GSB、理由、保存、实际本机提交计数与净胜率；三产品联合排名、并列与连续名次校验 |
| 结果看板 | 固定演示统计、场景筛选、ECharts 雷达和高频标签条形图、维度得分表、CSV 导出 |
| 数据同步 | 三阶段同步说明、JSON 演示备份导出、导入预览与确认恢复 |

## 数据与交互边界

- 所有预置数据均为演示。50 条题目重复使用四种占位需求；原图为同一 AI 生成素材，不是竞品真实输出。裁剪与色调变体仅用于展示图片槽位。
- 浏览器 IndexedDB 使用独立预览数据库。上传图片不外传，保存草稿或提交时，与记录在同一事务中保存；读取后尚未保存的修改可能在关闭页面时丢失。
- 题内切题时会保存有修改的草稿；切换主页面前应先保存。身份选择仅改变显示，不认证用户、不转移原有记录。
- 未提交的空白维度显示缺失；已选标签可预览该维度分数。零出图时图片维度不显示满分。G 维度在正式版还需要结合走查，当前页面只预览其标签部分。
- GSB 与联合排名单独保存。同一题同一产品对重复保存会更新本机演示判断，不重复计数。尚未实现正式不可变修订历史。
- 看板使用固定演示数据，独立于本机草稿；配置页的本地权重修改不会改写仓库 JSON，也不会改变当前演示看板。
- 当前导入是预览备份恢复，确认后相同键会被替换，应先导出本机备份。正式 ZIP、规则摘要、文件哈希、盲复评包与冲突合并尚未实现。
- 本次没有发布网站或推送 GitHub。源码可继续迭代，用户确定仓库后再配置部署。

## 已完成验证

- TypeScript 类型检查与生产构建。
- 十个评分单元测试：草稿缺失、无标签满分、严重等级优先、GSB 空集合/平局分母/全负、复评 3/10 与 4/10 触发边界及未完成集合。
- 浏览器检查主要页面与实际交互，包括标签预览、草稿保存、提交下一题、GSB 保存和计数、权重校验、看板场景筛选。

图片的生成方式与完整提示词见 [演示素材说明](demo-asset.md)。
