# 离线评测的可见范围与独立判断

本文只定义第 3 步的工作流边界，适用于三人离线评测、负责人合并数据的 V1，不增加账号系统或服务端权限。

## 1. 可见范围的含义

负责人也是三名评测员之一，负责分发、合并和组织讨论。姓名及职责是本地工作标识，不是经过认证的身份。页面按空间、任务和阶段隐藏数据，只能防止误看；本地文件及浏览器数据可被持有者主动读取，不能据此宣称权限隔离或对抗性安全盲评。

| 阶段 | 判断提交前可见 | 提交后及讨论时可见 |
| --- | --- | --- |
| 校准 | 统一题目、规则、图片及自己的判断 | 收齐三人的独立判断后，统一展示差异并讨论 |
| 初评 | 本人任务、生成证据、本人标签和记录 | 负责人在汇总空间合并；其他人的判断不自动进入个人空间 |
| 交叉复评 | 目标题目、验收要点、相同图片证据及本人复评 | 复评提交并合并后，才在讨论空间揭示原判断与差异 |
| 联合排名 | 同题各产品最佳图、需求与验收要点 | 三人共同形成排名，允许并列；此前的分数和 GSB 默认隐藏 |
| GSB | 指定产品对的同题图片与验收要点 | 提交后进入讨论；判断前隐藏标签、维度分及联合排名 |
| 裁决 | 已完成的初评、复评、证据及差异 | 三人讨论形成裁决与理由，写入独立记录 |

联合排名是共同结论，GSB 是另一类比较记录，二者分别保存，不能用排名自动补填尚未作出的 GSB。产品名称按项目既定方式展示；隐藏原评分不等于隐藏产品身份。

同一参与者同时做直接 GSB 与联合排名时，重叠题的独立 GSB 先于联合讨论提交。若已经参与相关讨论，记录其已见状态，不能把记忆中的结论视为已被界面隐藏。校准题与复评题可能重叠，也保留其已参加校准的事实，不静默换掉抽中的题目。

## 2. 校准与正式评测

校准使用 5 题及项目规定的各产品输出，三人先独立判断，再由负责人合并揭示。讨论形成的锚点和规则修订要保留来源；正式初评使用校准后确认的规则版本。校准原判断不被讨论结论覆盖，也不并入正式交叉复评一致率。

初评期间，个人空间不展示他人的问题统计或产品排名。存疑备注留在本人记录中，进入指定讨论时再揭示。规则修订不能静默改变已有分数，须明确受影响的记录及是否需要复查。

## 3. 复评包必须实际剔除答案

复评包保留题目、参考图、验收要点和待复评的同一组证据；最佳图引用保持一致，避免两人实际上判断不同图片。包内只保留完成复评所需的客观记录。

目标题的初评标签、严重等级、维度分、总分、备注和存疑理由必须从包中剔除，不能只在页面折叠。可用张数、可用性结论、高频问题统计、否决标记、既有裁决等可反推判断的字段也不携带。文件名、元数据及附带报告不得夹带上述答案；同时避免从产品汇总反推出目标题结论。

已导入完整包的浏览器仍保有旧数据，新建一个页面或更换姓名不会消除它。复评应使用未导入完整包的独立浏览器配置，并创建隔离的复评空间；该空间不自动关联已有完整项目。若当前空间已有目标题初评，必须停止盲评导入并提示更换空间及浏览器配置，不自动删除原数据。

负责人兼任复评员时，主包先进入汇总空间的暂存区，导入预览只显示数量和完整性；从暂存数据生成定向包后，在独立浏览器配置中完成自己的复评，再显式展开原评分。系统仍不能阻止负责人主动读取暂存数据。

刷新后继续当前复评空间；切换显示姓名不解锁原评分、不切入负责人汇总空间。复评空间不接收完整包，揭示差异须在独立的讨论空间显式进行。该流程降低意外泄露，不能约束主动查阅备份的人，也不能消除已经看过结果的记忆。

## 4. 原判断、裁决与最终引用

初评、复评、裁决分开保存，并关联同一题目、产品、证据和规则版本。独立判断提交后保留原记录；修订以新记录说明原因，不用裁决回填或改写初评、复评。

最终结果通过 `final` 引用使用的记录：无争议时引用确认的初评，有裁决时引用裁决记录。裁决记录注明参与人、理由和所引用的原判断。重新讨论产生新裁决及新的最终引用，旧记录仍可追溯。

## 5. 一致率与复查触发

依据原规则，每题只要任一受复评维度的分差达到 2 分，或 P0、P1 标签判定不一致，即记为不一致；不能用总分接近抵消分歧。

为便于实现，本稿建议把 P0/P1 差异定义为双方 `(标签编码, 实际严重等级)` 的高严重等级集合不同；包含一方判为 P1、另一方判为 P2，以及同一标签 P0 与 P1 的变化。两方只在 P2/P3 上不同、单维度分差不足 2 时，不自动触发不一致。该细化口径需在正式规则配置时确认并冻结。

本稿建议图像交叉复评覆盖 A、B、C、F，使用相同最佳图；G 的生成操作体验需要可重放操作证据才能独立复评，D 的编辑走查与 E 的量化指标另行核验。最终复评范围写入任务，缺少证据或不适用的维度不按无标签记为 5 分。范围在正式发布任务前确认。

每个产品抽取 10 题交叉复评，不一致超过 3 题，即至少 4 题时，触发该产品全部 50 题复查。未完成的复评标为待完成，展示实际完成数与计划数，不提前呈现完整一致率。

复评一致率按原始独立判断计算：一致题数除以已完成的成对复评题数。裁决后的共识可另记为已解决，但不能据此把原一致率重算成 100%。复查产生的新判断同样保留版本，并更新最终引用。
