# 项目重新开始与回收站

首题提交、正式开始或分发后，题库和规则保持冻结，避免已评记录与新题库混用。若试填后需要更换题库，可创建新草稿重新开始；旧数据不需要先删除。

## 重新开始

入口：

- “我的项目”中，每张项目卡片下方的“重新开始”。
- “项目与题库”页顶部的“重新开始”；配置冻结提示中也提供同一入口。

弹窗中填写新项目名称，选择题库处理方式：

1. **清空题库，重新导入**（默认）：保留计划题量，进入新项目的“题库管理”上传 CSV / JSON。
2. **保留现有题目**：复制已保存的题目元数据，新项目中可以编辑或整体替换。图片文件仍需重新上传。

两种方式都复制已保存的背景、周期、成员、产品及评分规则设置。新项目、成员和产品会获得新 ID，负责人引用重新映射；费用、商用核验、规则确认状态会重置。不复制评分、生成图片、参考图文件、质检判断、同步记录或归档；原项目保持原样。

新草稿的全部配置可以编辑。确认题库、产品及评分规则后再开始。团队若使用新草稿，需要重新分发新项目的准备包，旧项目的提交包不能直接合入新项目。

当前页面未保存的编辑不在复制范围内，弹窗会提醒。若需要保留这些修改，请先取消操作并保存配置。

## 移入回收站与恢复

“我的项目”卡片下方或“项目与题库”顶部点击“移入回收站”，确认项目名称后完成操作。主列表隐藏这个项目，评分记录、图片、历史快照和已有归档全部保留。

从“我的项目”右上角进入“回收站”，点击“恢复项目”即可找回。访问回收站项目的旧网址时，也会显示专门的恢复入口。

恢复保持原来的配置锁定和评分状态。需要重新导入题库时，应使用“重新开始”，而非通过恢复解除冻结。

此操作仅影响当前浏览器，不撤销其他评测员电脑上的副本，也不会自动释放图片存储空间。当前不提供永久删除或自动清空；清除浏览器站点数据仍会丢失本机全部数据，应通过已有项目备份或阶段包保留外部副本。

## 数据兼容与并发

数据库从 v4 升级到 v5，仅新增独立的 `projectTrash` 存储。回收站标记不进入 Project，不改规则/题库摘要、同步身份或旧备份格式。

配置、评分与图片、走查、质检、阶段合并、新归档等写事务都会检查回收站标记。另一标签页即使仍显示旧项目，也不能继续保存；同 ID 的备份和阶段包必须先恢复项目，不能绕过回收站。既有归档及独立评审空间保持原有内容。回收和恢复均不删除共享图片 Blob。

## 验证

247 项自动测试与生产构建通过。浏览器使用独立合成数据验证了已提交首题的项目重新开始、空题库重新导入、评分和媒体从零开始、主列表与回收站切换、旧网址恢复、旧标签页保存拦截，以及恢复后的原评分和原图保留。未移动或重置真实课程评测项目。
