# 每人一个竞品，共用自家基准

2026-10-22 决策：本次课程评测采用各竞品分别对自家的流程，不再要求竞品之间联合排名。原有初评、图片、质检和判断修订保留。

## 分工

- 每位评测员负责一个竞品的全部题目初评，以及该竞品与自家的逐题 GSB。
- 自家同题结果由指定负责人统一准备，供各组复用，无需每人重新生成或重新评分一遍。
- 三个竞品、50 题时，共 150 次 GSB；每人 50 次。自家初评是一份共同基准。
- 大家共用同一个准备包与项目 ID。已完成的竞品初评继续使用，通过阶段同步汇合，不要求重做。

## 入口和操作

正式项目侧边栏新增 **自家对比 GSB**，替换主导航中的联合排名入口。页面列出各产品的负责人、有效初评进度和对比分工。

1. 通过阶段同步汇合自家与本次竞品的初评记录及原图。
2. 选择“本次负责的竞品”，确认判断口径，建立任务。仅检查自家与所选竞品的全部题目；其他竞品可稍后准备。
3. 任务自动分给该竞品负责人。选择对应批次和领取成员，生成独立任务包。
4. 在未保存本项目完整数据的浏览器个人资料中打开独立评审空间，导入任务包，逐题比较同题最佳图，选择自家更好、两者相当或竞品更好。
5. 导出独立判断，负责人在 GSB 页收回。各组净胜率分别统计，平局进入分母，无法判断排除。模拟对象单列。

同一竞品不能重复建立任务，已有任务固定原初评修订和图片。后续初评变化不会静默替换 GSB 证据；报告继续检查过期证据。按竞品分批不改变题库、评分规则、发送范围或接收空间隔离。

## 报告与归档

- 当前报告采用 `report-v3`：不再检查联合排名完成情况，不要求场景排名配额。
- 报告展示自家与各竞品的 GSB、评分、优势短板和改进启示。典型案例从已有有效 GSB 且固定证据未过期的题目中选 3–5 组，引用判断 ID、任务 ID、双方最佳图及 SHA-256。
- 校准、交叉复评、分歧处理和原图完整性检查继续保留。取消竞品联合分析不代表这些质量任务自动完成。
- 已有联合排名作为历史数据保留，旧链接仍可访问；当前报告不把它当作完成条件。
- 旧 `report-v1` / `report-v2` 归档仍按各自的检查和原文本重新验证，不能因为新流程而把旧缺口补成已完成。

## 验证

覆盖 4 产品 / 3 人 / 50 题的 150 个 GSB 任务，无竞品之间的任务；按竞品分组启动与去重；没有联合排名的正式报告及最终归档；未知、无法判断、缺少和过期判断不补成有效案例；新旧报告版本与原图分包往返。

浏览器验收使用独立合成项目：其他两个竞品均为 0/3 时，已完成竞品与自家可以建立 3 题任务；已完成 GSB 的另一项目直接选择三个案例并保存报告结论。没有修改真实评测记录。
