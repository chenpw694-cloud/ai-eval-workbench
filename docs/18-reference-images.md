# 参考图的更正与保留

## 操作方式

逐题评测 → 展开“题目与参考图”：

- 鼠标移到参考图卡片时，右上角浮现圆形 ×；点击后移除当前参考图。
- 点击图片仍然放大查看；图下方“替换”用于选择正确文件，必需槽位沿用原来的文件名。
- 移除、替换或恢复后，点击“保存草稿”或正式提交才会写入本机。未保存切换题目或离开页面会提醒。
- “已移除参考图”可以预览和恢复已保存的旧图；恢复同名图片会替换当前选择。
- 键盘焦点进入卡片也显示 ×；无悬停能力的触屏直接显示 ×。按钮提供可访问名称、焦点环和按压反馈，遵循减少动态效果设置。

本题各产品共用参考图。移除必需参考图后，槽位变为“待上传”，可以保存草稿；补齐后才能正式提交。更正素材不会修改已冻结的题目要求。已提交评测保留当时采用的参考图，便于复核。

## 数据设计

图片元数据和原始字节保持不变。`referenceRevisions` 按题目记录当前选中的图片 ID，每次更正追加修订，空列表表示明确移除全部图片。保存评测、添加图片和追加参考图修订在同一 IndexedDB 事务中完成；保存时检查预期父版本，阻止旧页面覆盖更新。

新增评测记录通过 `referenceIds` 固定所用参考图。旧记录没有该字段时继续原有校验规则；旧素材没有修订历史时，按文件名采用最新上传的图片，时间相同按 ID 确定顺序。旧文件仍可在已移除列表中恢复。

数据库升级到版本 6，新增参考图修订存储。完整备份、阶段包、合并审计和版本归档保留修订与旧图；不通过物理删除原图实现移除。新质量任务固定参考图证据，后续更正不改变已分配的任务。

## 同步兼容

包含参考图修订、评测固定参考图或质量任务固定参考图的备份与阶段包使用 `schemaVersion: 3`。旧版 1、2 数据仍可导入；旧版本号夹带新字段会拒绝，防止旧客户端忽略移除结果。

同一修订 ID 的内容不得改写。同一题目两台电脑各自更改参考图形成分叉时，合并明确阻断；请由一个人更正参考图并分发最新阶段包，再继续协作。多人使用前应刷新到同一网站版本。

## 验证

核心测试覆盖移除、恢复、同名替换、空引用、版本冲突、图片归属、备份及阶段包兼容、质量证据固定。浏览器使用合成项目验证悬停显示、移开隐藏、图片放大、移除后保存刷新、恢复后再次保存，以及替换后必需槽位仍正确关联。
